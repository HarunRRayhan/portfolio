| D-001 | 2026-11-03 | Client IP comes from `CF-Connecting-IP` (set by Cloudflare, overwritten on every proxied request), applied by a global middleware to `REMOTE_ADDR`. `X-Forwarded-For` is no longer trusted for the client IP; `trustProxies` stays `*` for proto/port only. Cloudflare IP ranges are not used because Railway's edge sits between Cloudflare and the app, so `REMOTE_ADDR` is never a Cloudflare address. Same response whether or not the address exists. | Decided | none | `tests/Feature/SubscriberTest.php` passes; `grep -n "'subscribed'" app/Http/Controllers/NewsletterController.php` shows it only in `confirm` |
